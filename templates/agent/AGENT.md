# Agent charter template

## Mission
State the outcome, intended user and why this role exists.

## Accountability
One owner, explicit project scope, collaborators and escalation path.

## Responsibilities
Concrete deliverables and verification obligations.

## Non-goals
Excluded work, private data boundaries and actions requiring approval.

## Context
Link the canonical project, policies, dated decisions and relevant procedures.

## Acceptance
Visible evidence of success, failure conditions and a bounded next action.
